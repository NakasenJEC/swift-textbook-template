## 質問と回答の記録

### Q1

**質問：**
このコードで `struct Song: Codable, Identifiable` と書いていますが、`Codable`とは何ですか？なぜこれをつけるだけでJSONから自動的にデータが取れるのですか？

**AIの回答の要点：**
`Codable`は`Encodable`と`Decodable`の2つのプロトコルを合体させたもの。`Decodable`を採用すると、Swiftコンパイラが自動的に「JSONのキー名とプロパティ名を照合してデータを入れるコード」を生成してくれる。条件はプロパティ名とJSONのキー名が一致していること。もし名前が違う場合は`CodingKeys`という列挙型を使って対応付けを手動で書ける。

**自分の理解：**
Swiftがコンパイル時に自動生成してくれるので「魔法」に見えるが、実際にやっていることは「JSONの`trackName`というキーを探してSwiftの`trackName`プロパティに入れる」という単純な照合。名前を一致させれば自動、違う場合は`CodingKeys`で手動マッピングという使い分けが分かった。

### Q2

**質問：**
`func searchMusic() async` の`async`と、`await searchMusic()`の`await`はそれぞれ何をしているのですか？なぜ両方書かないといけないのですか？

**AIの回答の要点：**
`async`は「この関数は完了するまでに時間がかかる可能性がある非同期関数だ」という宣言。`await`は「ここで非同期関数を呼び出す。完了するまでここで待つ」という目印。非同期関数を呼ぶ側は必ず`await`を付けないと呼べないというルールがある。これによってコンパイラが「ここで処理が止まりうる」という箇所を把握できる。

**自分の理解：**
`async`は関数の「性質」を表し、`await`は呼び出し側の「姿勢」を表す。`async`だけあっても`await`なしに呼ぼうとするとコンパイルエラーになる。これはコードを読む人に「ここでネットワーク待ちが発生する」という情報を強制的に伝えるための設計だと分かった。

### Q3

**質問：**
`guard let encodedText = searchText.addingPercentEncoding(withAllowedCharacters: .urlQueryAllowed) else { return }` の`addingPercentEncoding`は何をしているのですか？なぜ必要ですか？

**AIの回答の要点：**
URLには使える文字と使えない文字がある。日本語・スペース・一部の記号はURLに直接含められない。`addingPercentEncoding`はこれらの文字を`%E3%81%82`のような「パーセントエンコード」に変換する。例えばスペースは`%20`、「あ」は`%E3%81%82`になる。これをしないと作られたURLが不正な形になってリクエストが失敗する。

**自分の理解：**
iTunesで日本語アーティスト名（例：米津玄師）を検索する場合、そのままURLに入れると文字化けして正しく検索できない。エンコードすることで文字列が`%XX`形式に変換され、サーバーが正しく受け取れるようになる。実際に`addingPercentEncoding`を外して日本語で検索したら結果が0件になって確認できた。

### Q4

**質問：**
`var id: Int { trackId }` という書き方は何ですか？変数なのに`{}`があるのが不思議です。

**AIの回答の要点：**
これは「computed property（計算型プロパティ）」と呼ばれる。値を保存するのではなく、アクセスされるたびに`{}`の中の式を評価して値を返す。`var id: Int { trackId }`は「`id`にアクセスしたら`trackId`の値を返す」という意味。`Identifiable`プロトコルは`id`というプロパティを要求するが、`trackId`がすでに一意なIDとして機能しているので、同じ値を二重に持たず計算プロパティで済ませている。

**自分の理解：**
`let id = trackId`と書いても同じ結果になるが、`let id`だと2つの変数がメモリに存在することになる。`var id: Int { trackId }`は「エイリアス」のようなもので、メモリを節約しながら`Identifiable`の要件を満たせる。computed propertyはSwiftでよく出てくるパターンだと分かった。

### Q5

**質問：**
`ProgressView("検索中...")`は何ですか？どうやって「検索中」という状態を知るのですか？

**AIの回答の要点：**
`ProgressView`はiOS標準のローディングインジケーター（くるくる回るアイコン）を表示するSwiftUIコンポーネント。検索中かどうかは`@State private var isLoading: Bool`フラグで管理する。`searchMusic()`が始まると`isLoading = true`、終わると`isLoading = false`に設定する。`@State`が変わるとSwiftUIが自動的にビューを再描画するため、フラグを切り替えるだけでUIが自動更新される。

**自分の理解：**
「状態変数（State）を変えればUIが自動で更新される」というのがSwiftUIの根本的な仕組み。UIを直接操作するのではなく、データ（State）を操作するとUIが追随してくる。これがUIKitとの大きな違いだと分かった。
